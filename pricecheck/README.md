# OppoGlobe PriceCheck starter
Install `pricecheck` in INSTALLED_APPS and route `/pricecheck/` (already included in patch). Run `python manage.py makemigrations pricecheck` and `python manage.py migrate` in your environment. Use Django admin for products/retailers or `python manage.py import_pricecheck_csv approved_feed.csv` for merchant-approved data. Required CSV columns: retailer,product,retailer_sku,price. Optional: category,brand,barcode,product_url,branch. No unauthorised scraping or live retailer connections are included. This is a functional starter with a responsive UI, search, offers and CSV ingestion; add production security, feed scheduling and end-to-end tests before launch.
